# Lunar Frontier: The Last 30 Days — Asset Registry & Licensing

This document records the provenance, licensing, and attribution requirements for all external 3D models, textures, audio recordings, and fonts utilized in **Lunar Frontier: The Last 30 Days**.

---

## 1. NASA Scientific Visualization Studio & Planetary Resources
- **NASA CGI Moon Kit**:
  - **Source**: NASA's Scientific Visualization Studio (SVS)
  - **URL**: https://svs.gsfc.nasa.gov/4720
  - **Assets**: Lunar reconnaissance orbiter (LRO) elevation displacement map & high-resolution photographic albedo mosaic.
  - **License**: Public Domain (NASA Open Data Policy)
  - **Attribution**: "Imagery and elevation data courtesy of NASA's Scientific Visualization Studio and the Lunar Reconnaissance Orbiter (LRO) Camera team."
- **NASA 3D Resources (Spacecraft, Landers, Tools)**:
  - **Source**: NASA Science 3D Resources / GitHub NASA 3D
  - **URL**: https://science.nasa.gov/3d-resources/
  - **Assets**: Artemis lunar lander, lunar roving vehicle chassis, spacesuit exterior geometries.
  - **License**: Public Domain (US Government Work)
